How to play

Drag from an animal to its partner to draw a path between them. Paths go up, down, left and right, never cross, and between them they fill every square.

Drag back along a path to shorten it. Drawing across another path cuts that path back. Tap an animal to clear its path.

Every paddock has exactly one answer. Stuck? A hint shows where one pair's path begins; a second hint draws all of it.

Keyboard: arrow keys move between squares. Enter on an animal or the end of a path picks it up, arrow keys draw, and Enter or Escape puts it down. Delete clears a path and Ctrl+Z undoes. With a screen reader, activate an animal, then each square along its path in turn. A new paddock arrives at midnight: small and gentle on Monday, big and tricky by Sunday.
